RapideVite real packshots — batch 2 (50 products)

This package contains 50 recognizable products selected from the market photos.

It includes:
- requested_products.csv
- fetch_real_packshots.py
- PROMPT_FOR_CLAUDE.txt

The script searches Open Food Facts and downloads actual front-of-package product images.
It does not generate images and does not use shelf crops.

Upload this ZIP directly to Claude and paste the prompt from PROMPT_FOR_CLAUDE.txt.

Important:
The script scores matches automatically, but you must review the contact sheet before importing.
Packaging can vary by country and size.
